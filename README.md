# Customer Data Analysis Project

**Project Overview**
This project focuses on analyzing customer shopping data to understand customer purchasing behaviour, product sales, and revenue patterns.
**Tools Used**
- Excel
- SQL
- Power BI
**Project Objectives**
- Analyze customer purchasing behaviour.
- Understand sales by gender and age groups.
- Identify popular product categories.
- Analyze revenue and payment methods.
- Create an interactive Power BI dashboard.
**Key Analysis**
- Customer distribution by gender.
- Revenue by gender.
- Product sales by age group.
- Sales by product category.
- Payment method distribution.
- Shopping mall performance.
**Project Files**
- SQL Queries
- Customer Dataset
- Power BI Dashboard
- Project Documentation
**Conclusion**
This project helped me develop practical skills in SQL, Excel, Power BI, and data analysis by extracting meaningful insights from customer shopping data
